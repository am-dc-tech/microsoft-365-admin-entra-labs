# Microsoft Admin Center Labs

Hands-on help desk labs in the Microsoft 365 Admin Center. Each ticket is a realistic help desk scenario, documented from intake to resolution with step-by-step notes and screenshots.

## Skills Demonstrated

- User onboarding and account creation in Microsoft 365 Admin Center
- User and license management in Microsoft 365 Admin Center
- Password resets and account unlocks
- Troubleshooting sign-in errors
- User offboarding and account deprovisioning
- Ticket documentation and end-user communication
